# Screen Specification: Training (Workout Log)

## Overview
Efficient workout logging screen optimized for high-intensity training.

## Layout Components

### 1. Workout Header
- Date Selector.
- Session Title (e.g., "Leg Day").
- Session Duration Timer.

### 2. Exercise List
- Each exercise is a card.
- **Set Table:** columns: Set, Weight, Reps, RPE, Status.
- **BIG3 Priority:** SBD exercises are automatically moved to the top if present.

### 3. Log Controls
- "Add Set" button.
- "Copy Previous Set" (Ghost text feature: shows values from the previous session for quick entry).
- "Finish Workout" button.

## User Actions
- Record weight, reps, and RPE for each set.
- Reference previous performance.
- Add/Remove exercises.
