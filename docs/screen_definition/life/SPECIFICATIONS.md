# Screen Specification: Life (Metrics)

## Overview
Quick entry screen for physiological data (Body weight) and nutritional summaries.

## Layout Components

### 1. Weight Input Card
- Massive numeric input for today's weight (kg).
- Trend indicator (e.g., "-0.5kg from yesterday").

### 2. Nutrition Input Card
- Total Calories (kcal).
- Protein (g), Fat (g), Carbohydrate (g).
- Simple progress bars showing PFC balance.

### 3. Daily History
- A simple list or calendar view showing the last 7 days of entries for quick review.

## User Actions
- Input daily body weight.
- Input total daily calorie/PFC intake (entered manually from other apps or logs).
