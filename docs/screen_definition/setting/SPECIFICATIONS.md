# Screen Specification: Setting

## Overview
User profile and application configuration.

## Layout Components

### 1. Profile Section
- Current SBD Personal Bests (PBs).
- Experience Level (Novice, Intermediate, Advanced).

### 2. Goals Section
- Target 1RMs for Squat, Bench Press, and Deadlift.
- Target Body Weight.

### 3. Application Settings
- Unit preference (kg/lbs).
- Notification settings.
- Subscription status (Free/Pro).

## User Actions
- Update goals.
- Manage profile.
- Upgrade to Pro (Unlock Analysis).
